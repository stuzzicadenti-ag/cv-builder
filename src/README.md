# CV Builder

Free, professional CV/resume builder supporting Europass, LaTeX, and Typst formats.

**Live site:** [stuzzicadenti-ag.github.io/cv-builder](https://stuzzicadenti-ag.github.io/cv-builder/)

## Features

- Professional dark-themed landing page
- 6 curated CV templates (Europass 2024, Modern Minimal, Academic LaTeX, Creative Typst, Tech Professional, Executive)
- ATS-optimized output that passes Applicant Tracking Systems
- Multi-language support (EN, IT, DE, FR, ES)
- One-click PDF export
- Privacy-first: data stays in the browser
- Fully responsive, mobile-first design
- Login/Register modal (CSS-only tab switching)
- Full SEO: Open Graph, Twitter Cards, Schema.org markup

## Supported Formats

| Format | Description |
|--------|-------------|
| **Europass** | EU standard CV recognized across Europe |
| **LaTeX** | Pixel-perfect academic typesetting |
| **Typst** | Modern, fast typesetting with clean syntax |
| **PDF** | Universal export format |

## Tech Stack

- Pure HTML5 + CSS3 (no JavaScript frameworks)
- No external dependencies
- CSS custom properties for theming
- CSS-only responsive navigation and modal
- Hosted on GitHub Pages

## Self-Hosting

Download or clone the repository and open `src/index.html` in any browser. No build step required.

```bash
git clone https://github.com/stuzzicadenti-ag/cv-builder.git
cd cv-builder/src
# Open index.html in your browser
```
